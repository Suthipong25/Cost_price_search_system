ระบบค้นหาราคาต้นทุนรถ (React + PostgreSQL Version)

ขั้นตอนการเชื่อมต่อกับ PostgreSQL (Step-by-Step)
1. ตั้งค่าการเชื่อมต่อฐานข้อมูลในไฟล์ .env (ระบุ Host, Port, User, Password, DB Name)
2. ดับเบิ้ลคลิกไฟล์ seed.bat เพื่อสร้างตาราง vehicle_costs และนำเข้าข้อมูลตั้งต้น 464 เส้นทาง (740 รายการราคา) เข้าฐานข้อมูล PostgreSQL
3. ดับเบิ้ลคลิกไฟล์ start_all.bat เพื่อเปิดระบบพร้อมกันทั้ง Backend API (Port 5000) และ React Web (Port 3000)
4. เมื่อแก้ไขราคาหรือเพิ่มข้อมูลใหม่ ระบบจะบันทึกลงฐานข้อมูล PostgreSQL จริงทันที ไม่เก็บใน localStorage ของเบราว์เซอร์

วิธีเริ่มใช้งาน
1. ดับเบิ้ลคลิก start_all.bat (หรือ start_dev.bat หากต้องการทดสอบเฉพาะหน้าเว็บ)
2. ระบบจะเปิดหน้าเว็บขึ้นมาที่ http://localhost:3000 โดยอัตโนมัติ
3. หน้าเว็บจะแสดงสถานะ "🟢 ฐานข้อมูล: PostgreSQL (Connected)" ที่ด้านล่าง แสดงว่าเชื่อมต่อกับฐานข้อมูลเรียบร้อยแล้ว
4. พิมพ์ TO หรือจังหวัดปลายทางเพื่อกรองผลลัพธ์ให้แคบลง โดยช่องจังหวัดรองรับทั้งชื่อภาษาอังกฤษและภาษาไทย
5. รายการคำแนะนำจะเปิดใต้ช่อง สามารถคลิกเลือก หรือใช้ปุ่มลูกศรขึ้น/ลงแล้วกด Enter ได้
6. สามารถเลือก "ประเภทรถ" เพื่อกรองดูเฉพาะประเภทรถที่ต้องการได้
7. กดปุ่ม "คัดลอก" เพื่อคัดลอกตารางข้อมูลทั้งหมดไปวางในโปรแกรม Excel ได้ทันที หรือกด "พิมพ์" เพื่อพิมพ์เอกสาร

รายละเอียดในตาราง
- แสดงหัวคอลัมน์ตามไฟล์ Excel: From, รับ, To province, To City, To location และ ส่ง
- แสดงรายละเอียดจากแถวต้นทางของแต่ละบริษัท พร้อมประเภทรถ ราคาต้นทุน และราคาบวกเปอร์เซ็นต์
- ช่องรายละเอียดที่ไม่มีข้อมูลใน Excel จะแสดงเป็น — ในตาราง และเป็นช่องว่างเมื่อคัดลอกไป Excel

หลักการคำนวณและแสดงผล
- แสดงราคาต้นทุนของทุกบริษัท และมีป้าย "ต่ำสุด" กำกับราคาที่ถูกที่สุดในแต่ละประเภทรถ
- คำนวณราคาขายบวก 10%, 12%, 15%, 18%, 21%, 24%, 27% และ 30% ให้ครบทุกระดับ

การอัปเดตและแก้ไขข้อมูล
- ปุ่ม "เปิดไฟล์บน SharePoint": เปิดไฟล์ Excel ต้นฉบับบนระบบ Microsoft SharePoint (Perkin Logistics) เพื่อดูหรือแก้ไขราคาออนไลน์ได้ทันที
- ปุ่ม "อัปเดตจาก Excel": เมื่อดาวน์โหลดไฟล์ Excel ล่าสุดจาก SharePoint สามารถกดปุ่มนี้เพื่อนำเข้าไฟล์ .xlsx เข้าสู่ระบบค้นหาได้ทันทีในหน้าเว็บ
- ปุ่ม "ส่งออก Excel": ส่งออกข้อมูลราคาและเปอร์เซ็นต์ทั้งหมดเป็นไฟล์ .xlsx ล่าสุด สำหรับนำไปอัปโหลดทับบน SharePoint
- สคริปต์ update_from_excel.bat: หากนำไฟล์ Excel มาวางไว้ในโฟลเดอร์นี้ สามารถดับเบิ้ลคลิก update_from_excel.bat เพื่อแปลงข้อมูลลง data.js อัตโนมัติ
- ปุ่ม "แก้ไข": ในช่องราคาต้นทุนของแต่ละแถว สามารถกดแก้ไขราคาได้ทันที โดยระบบจะคำนวณราคาบวกเปอร์เซ็นต์ (10%–30%) และป้าย "ต่ำสุด" ให้อัตโนมัติ
- ปุ่ม "เพิ่มข้อมูลใหม่": เปิดแบบฟอร์มเพิ่มรายการเส้นทางหรือบริษัทใหม่ได้โดยตรง
